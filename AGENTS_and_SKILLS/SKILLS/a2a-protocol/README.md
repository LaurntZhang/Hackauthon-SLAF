# A2A Protocol

Skill local pour concevoir une communication Agent2Agent gouvernée entre
agents FastAPI/LangGraph. Elle couvre Agent Cards, tâches corrélées,
idempotence, orchestration coordinateur/spécialistes et sécurité.

La référence d'origine étant orientée Google ADK, les exemples sont
volontairement adaptés à Pydantic et LangGraph.
