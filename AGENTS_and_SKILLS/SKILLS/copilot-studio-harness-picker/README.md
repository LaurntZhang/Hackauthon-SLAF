# Copilot Studio Harness Picker

Skill d’aide au choix entre les harness GitHub Copilot, Copilot Studio
standard et Copilot chat, ou une alternative Microsoft mieux adaptée.

Il distingue :

- le runtime/harness ;
- le modèle ;
- le canal de publication ;
- la forme de solution : workflow, agent, workflow avec nœud agent ou agent
  appelant un workflow.

Il fournit un **Harness Decision Brief** avec gates bloquants, architecture
cible, gouvernance, ALM, observabilité, coûts et conditions de renversement.
Les affirmations liées aux produits et tarifs doivent être revérifiées dans la
documentation Microsoft officielle.
