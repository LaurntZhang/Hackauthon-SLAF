# Skill Prompt Engineer Agents

1. Identifier le rôle et la surface d'action.
2. Définir le schéma Pydantic de sortie et les statuts d'escalade.
3. Injecter explicitement les faits nécessaires et séparer faits/instructions.
4. Réduire les ambiguïtés, répétitions et consignes contradictoires.
5. Produire avant/après et tester nominal, seuil et entrée malveillante.

Un prompt est validé seulement si l'échec est explicite et sûr.
