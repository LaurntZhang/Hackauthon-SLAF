# Paiement Agentique

Agent de prototypage x402/FastAPI/Pydantic pour le sujet de portefeuille
agentique. Il sépare le challenge de paiement, le contrôle de mandat, la preuve
et le reçu, avec simulation testnet hors ligne.

Le script `scripts/x402_mock_flow.py` montre le flux sans clé privée ni RPC.
