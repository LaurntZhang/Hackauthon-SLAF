# Architecte Solution

Agent francophone de cadrage d'architectures multi-agents pour la finance
autonome. Il produit un schéma Mermaid, les flux, les contrôles de mandat,
les points HITL, l'audit trail et un arbitrage MVP/production.

## Utilisation

Décrire le besoin métier, les contraintes de gouvernance et le délai de
livraison. Le script `scripts/scaffold_project.py` peut générer un squelette
de projet minimal.
