# Skill Security Quick Audit

Collecter les preuves, tracer le flux exploitable, qualifier la criticité,
proposer le correctif minimal et vérifier si le risque bloque la démo. Ne pas
confondre un pattern suspect avec une vulnérabilité confirmée.

Le rapport doit contenir les contrôles positifs et les risques résiduels, sans
révéler de secret découvert.
