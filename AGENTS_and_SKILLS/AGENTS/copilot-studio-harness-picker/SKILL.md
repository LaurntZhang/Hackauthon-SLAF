# Skill Copilot Studio Harness Picker

1. Décrire le résultat attendu et les frontières utilisateurs/canaux.
2. Tester les gates bloquants avant les préférences.
3. Séparer harness, modèle, canal et composants.
4. Choisir workflow, agent ou combinaison gouvernée.
5. Documenter identité, autorisation, ALM, observabilité et ownership.
6. Produire des scénarios de crédits datés, avec hypothèses et exclusions.
7. Lister les validations et les conditions qui inverseraient le choix.

Pour ce projet Finaxys, préserver l'architecture Python/LangGraph si elle est
le périmètre de la démo ; présenter Copilot Studio comme une alternative
architecturale lorsqu'il ne s'agit pas du runtime choisi.
