# Copilot Studio Harness Picker

Agent de décision d'architecture pour choisir un harness Copilot Studio ou une
alternative Microsoft. Complémentaire des agents LangGraph et FastAPI : il ne
remplace pas l'implémentation locale, mais aide à comparer une cible
Copilot/Microsoft avec des contraintes explicites.

Source officielle :
https://microsoft.github.io/cat-agent-skills/skills/copilot-studio-harness-picker/
