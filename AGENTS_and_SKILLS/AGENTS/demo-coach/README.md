# Demo Coach

Agent de préparation du pitch Finaxys : il transforme le comportement réel du
système en démonstration de cinq minutes, avec accroche métier, scénario nominal,
escalade HITL, vocabulaire réglementaire et plan B.

Le script `scripts/pitch_timer.py` aide à répéter le minutage et
`assets/demo_script_template.md` fournit une trame réutilisable.
