# Gouvernance Conformité

Agent d'audit des mandats, de la séparation des pouvoirs, des seuils HITL, de
l'audit trail et de l'explicabilité. Il restitue chaque pilier avec un verdict,
les preuves et un correctif minimal lorsque nécessaire.

`scripts/governance_audit.py` fournit une base d'analyse locale sans données
confidentielles.
