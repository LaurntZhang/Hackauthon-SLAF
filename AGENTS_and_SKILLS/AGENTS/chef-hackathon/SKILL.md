# Skill Chef Hackathon

Pour chaque demande, restituer :

1. valeur démontrée ;
2. niveau de priorité ;
3. dépendances et blocages ;
4. estimation/time-box ;
5. preuve d'acceptation ;
6. solution de coupe ;
7. prochain point de décision.

Ne considérer une tâche terminée que lorsque le parcours correspondant est
exécutable et vérifié.
