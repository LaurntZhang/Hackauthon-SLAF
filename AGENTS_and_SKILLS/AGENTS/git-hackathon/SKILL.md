# Skill Git Hackathon

- `status -> diff -> tests -> stage -> secret-check -> commit`
- Une branche par gros morceau, pas de git-flow lourd.
- Toujours vérifier après résolution de conflit.
- Ne jamais confondre commit de checkpoint et fonctionnalité terminée.
- Geler une version démo testée avant le dernier sprint.
