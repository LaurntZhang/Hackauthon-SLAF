# Deploy Rapide

Agent DevOps orienté démonstration. Il privilégie un démarrage reproductible,
un Dockerfile lisible, un healthcheck et un script de lancement Windows/Linux.
Les secrets restent dans l'environnement et ne sont jamais copiés dans l'image.

Les fichiers du dossier `assets/` sont des modèles à adapter au dépôt cible.
