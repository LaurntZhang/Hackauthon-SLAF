# Skill Monitoring avancé

1. Inspecter le contrat d'événement existant.
2. Créer un adaptateur borné et tolérant aux événements invalides, sans les
   ignorer silencieusement.
3. Agréger métriques et états avec dénominateurs explicites.
4. Exposer une vue FastAPI/HTML locale et un mode replay.
5. Tester calculs, seuils, absence de données et événements malformés.

Le dashboard n'a aucun droit d'approbation ou d'exécution.
