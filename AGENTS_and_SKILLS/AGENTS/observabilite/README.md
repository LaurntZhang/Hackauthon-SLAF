# Observabilité

Agent d'instrumentation locale et Langfuse : événements JSON structurés,
durées, statuts, justification et visualisation terminale. Le mode hors ligne
reste le chemin de démonstration par défaut afin qu'une panne réseau ne bloque
pas le graphe.

Les scripts `tracer.py` et `view_traces.py` sont conçus pour être adaptés au
logger du projet.
